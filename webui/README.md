# واجهة الويب لنظام ERP (عربية RTL)

واجهة متصفح فوق قاعدة Oracle: كل المنطق المحاسبي في حزم PL/SQL (`oracle/`)، والواجهة تستدعيها فقط (Express + node-oracledb بوضع thin، لا يلزم Oracle Client).

## ما يعمل الآن
- **المحاسبة:** دليل الحسابات (إضافة/تعديل اسم/إيقاف)، قيد يومية جديد (مؤشر توازن فوري)، دفتر اليومية مع العكس.
- **التقارير:** ميزان المراجعة، كشف حساب، قائمة الدخل، الميزانية، التدفقات النقدية، طباعة.
- **الإقفال:** إقفال/فتح الشهر مع فحص الملاحظات، إقفال/فتح السنة.
- **المبيعات والمشتريات:** العملاء والموردون وكشف حساب كل طرف، فواتير المبيعات والمشتريات (بنود حرة أو أصناف مخزنية تحرّك المخزون وتُرحَّل تكلفتها)، سندات القبض والصرف (على فاتورة أو دفعة على الحساب)، إلغاء الفاتورة غير المسدّدة، أعمار الديون.
- **المخزون:** الأصناف (إضافة، سعر وضريبة، إيقاف)، المخازن، أرصدة بالمتوسط المرجّح مع مطابقة الأستاذ، حركات المخزون، تسوية جرد/رصيد افتتاحي، تحويل بين المخازن.
- **الأصول الثابتة:** سجل الأصول مع مطابقة الأستاذ، أصل جديد وفئات، تشغيل الإهلاك الشهري وعكسه، بيع/استبعاد الأصل، إلغاء أصل لم يُهلك، جدول إهلاك كل أصل.
- **الرواتب والموارد البشرية:** الموظفون والأقسام وتاريخ الراتب وإنهاء الخدمة، مكوّنات الراتب (نسب وسقوف تعرّفها أنت)، التسويات الشهرية، السلف، كشوف الرواتب (إنشاء/حساب، ترحيل، صرف، إلغاء).
- لم تُبنَ بعد: نقاط البيع، الطلبات، العروض (تعمل من SQL حالياً).

## التشغيل على ويندوز (بدون تثبيت Node) — الأسهل
بعد تثبيت قاعدة البيانات (`oracle\local\install-local.ps1`) وأن حاوية Oracle تعمل:
```powershell
cd webui
powershell -ExecutionPolicy Bypass -File .\run-docker.ps1
```
يطبع كلمة سر الدخول (تُحفظ في `webui\.env-docker`) ثم افتح http://localhost:3001 (المستخدم `admin`).

لينكس/ماك: `./run-docker.sh`.

## التشغيل المباشر (Node 18+)
```bash
cd webui && npm install && npm run init && npm start
```
`npm run init` ينشئ `.env` (كلمة سر القاعدة من `oracle/local/.env`) ويطبع كلمة سر الدخول.

## الإعدادات (`.env`)
`ERP_DB_USER` · `ERP_DB_PASSWORD` · `ERP_DB_CONNECT` (الافتراضي `localhost:1521/XEPDB1`) · `ERP_WEB_PORT` (3001) · `ERP_WEB_HOST` (الافتراضي 127.0.0.1) · `ERP_WEB_USER` · `ERP_WEB_PASSWORD` · `ERP_WEB_SECRET` · `ERP_COOKIE_SECURE=1` عند HTTPS.

## الأمان — اقرأ قبل فتحها على شبكة
- مستخدم ويب واحد (admin) والاتصال بالقاعدة بحساب `erp_owner` واحد: لا فصل صلاحيات بين المستخدمين.
- يستمع الخادم على 127.0.0.1 فقط افتراضياً. لا تفتحه على الإنترنت دون HTTPS ووكيل عكسي.
- الجلسة بكوكي موقّع HttpOnly/SameSite=Strict، الطلبات الكاتبة JSON فقط، ترويسة CSP، وحد 5 محاولات دخول فاشلة/10 دقائق لكل عنوان.

## الاختبار
`npm test` (تكاملي على قاعدة حقيقية؛ يُتخطى دون كلمة سر القاعدة). لإضافة اختبارات الكتابة (ترحّل قيوداً فعلية): `ERP_TEST_WRITE=1 npm test`.

## ما اختُبر
جُرّبت على Oracle XE 21c: واجهة API (10 اختبارات)، ومتصفح Chromium (دخول، قيد، دفتر، التقارير، الفترات)، وصورة Docker تتصل بالقاعدة عبر `host.docker.internal`. لم يُجرَّب `run-docker.ps1` على ويندوز فعلياً، ولا `npm ci` داخل بناء Docker في بيئتي (حُجب الوصول للسجل).
