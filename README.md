# تمام برو

منصة مكتب محاسبة واستشارات بالعربية: مراجعة، استراتيجية، حوكمة، دراسات جدوى، محاسبة قضائية، مهام، ودفتر مقهى.
تعمل الآن بخادم **Node.js + SQLite** بدل تخزين المتصفح، فتُحفظ البيانات مركزياً ويصل إليها كل المستخدمين.

## التشغيل

```bash
npm install
npm start            # http://localhost:3000
```

أول زيارة تعرض صفحة إنشاء **حساب مالك المنصة**. بعدها يضيف المالك بقية الحسابات من `/admin.html`.
الدخول موحّد: حساب المنصة هو الهوية الوحيدة، ويُنشأ تلقائياً حساب الأقسام المقابل له عند أول دخول. المالك يمنح العضو الأقسام من صفحة «المستخدمون» داخل تمام برو (العضو الجديد لا يرى أقساماً حتى يمنحه المالك ذلك).

Docker: `docker compose up -d --build` (البيانات في الوحدة `erp-data`).

### نشر برابط عام (Render)

1. ادمج الفرع في `main`، ثم من Render: **New > Blueprint** واختر المستودع (يقرأ `render.yaml`).
2. أدخل `ANTHROPIC_API_KEY` إن أردت المساعد الذكي (اختياري).
3. بعد النشر افتح الرابط الذي يعطيك إياه Render؛ أول زيارة تنشئ حساب المالك، فأنشئه فورًا.

القرص الدائم (`/data`) يحفظ قاعدة البيانات والنسخ الاحتياطية، ويتطلب خطة مدفوعة. يصلح أي مزوّد آخر يدعم Docker مع قرص دائم.

| متغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | 3000 | المنفذ |
| `DB_FILE` | `data/erp.sqlite` | ملف قاعدة البيانات |
| `COOKIE_SECURE` | 0 | اجعله 1 خلف HTTPS |
| `TRUST_PROXY` | 0 | اجعله 1 خلف وكيل عكسي |
| `ANTHROPIC_API_KEY` | — | يفعّل المساعد الذكي في قسم المراجعة (المفتاح يبقى على الخادم) |
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | نموذج المساعد |
| `BACKUP` | 1 | نسخ احتياطي تلقائي عند التشغيل ثم كل 24 ساعة (0 للإيقاف) |
| `BACKUP_DIR` / `BACKUP_KEEP` | `data/backups` / 14 | مجلد النسخ وعدد النسخ المحفوظة |

فحص الصحة: `GET /healthz`.

## المعمارية

- `public/`: واجهة الموقع الأصلية (الغلاف `index.html` + 7 أقسام) دون تغيير تصميمها.
- `public/claude-shim.js`: يوفّر `window.claude.use('db' | 'user' | 'downloads')` الذي تعتمد عليه الأقسام، ويتصل بالخادم (قاعدة مستندات بأسلوب Firestore، تحديث فوري عبر SSE).
- `server/`: خادم Express، مخزن مستندات فوق SQLite، حسابات المنصة (scrypt) وجلسات HttpOnly وتقييد محاولات الدخول.
- `public/vendor/`: المكتبات والخطوط محلية (لا اعتماد على الإنترنت). لإعادة توليدها: `npm install && npm run vendor`.

## الاختبار والنسخ الاحتياطي

```bash
npm test            # اختبارات الخادم
npm run backup      # نسخة متسقة إلى data/backups
```

## حدود معروفة

- المساعد الذكي لا يظهر إلا مع وجود `ANTHROPIC_API_KEY`، وحدّه 20 طلباً في الدقيقة لكل مستخدم.
- حسابات الأقسام التي تُضاف يدوياً من صفحة «المستخدمون» لا تستطيع الدخول؛ أضف المستخدمين من `/admin.html`.
- أي مستخدم مسجّل في المنصة يستطيع تقنياً قراءة بيانات المكتب كلها عبر الواجهة البرمجية؛ فصل الصلاحيات الحالي يتم داخل واجهة كل قسم. أضف حسابات للموثوقين فقط.
