# تمام برو

منصة مكتب محاسبة واستشارات بالعربية: مراجعة، استراتيجية، حوكمة، دراسات جدوى، محاسبة قضائية، مهام، ودفتر مقهى.
تعمل الآن بخادم **Node.js + SQLite** بدل تخزين المتصفح، فتُحفظ البيانات مركزياً ويصل إليها كل المستخدمين.

## التشغيل

```bash
npm install
npm start            # http://localhost:3000
```

أول زيارة تعرض صفحة إنشاء **حساب مالك المنصة**. بعدها يضيف المالك بقية الحسابات من `/admin.html`.
الدخول موحّد: حساب المنصة هو الهوية الوحيدة، ويُنشأ تلقائياً حساب الأقسام المقابل له عند أول دخول. المالك يمنح العضو الأقسام من صفحة «المستخدمون» داخل تمام برو (العضو الجديد لا يرى أقساماً حتى يمنحه المالك ذلك).

Docker: `docker compose up -d --build` (البيانات في الوحدة `erp-data`).

### تشغيل على جهازك مع رابط عام مجاني

1. ثبّت Node 22 وcloudflared (ويندوز: `winget install Cloudflare.cloudflared`، ماك: `brew install cloudflared`).
2. `npm install` ثم `npm run share`.
3. يطبع الأمر رابطًا مثل `https://xxxx.trycloudflare.com`؛ شاركه مع من تريد. البيانات تُحفظ في `data/erp.sqlite` على جهازك، والرابط يتغيّر في كل تشغيل ويتوقف بإغلاق النافذة.

### تشغيل دائم على جهاز ويندوز

1. ثبّت Node 22 وcloudflared، وفكّ ضغط المشروع.
2. انقر مرتين على `scripts\windows\install.cmd`. يثبّت الاعتماديات وينشئ مهمة تبدأ مع تسجيل دخول ويندوز وتعيد التشغيل إن توقف الموقع، ويمنع سكون الجهاز أثناء الشحن.
3. بعد 15 ثانية اقرأ الرابط من `data\public-url.txt`. هذا رابط مؤقت يتغيّر عند كل إعادة تشغيل.
4. للإيقاف: `scripts\windows\uninstall.cmd`. السجل في `data\server.log`.

**رابط ثابت على نطاقك (مثل tmam.pro):** انقل سيرفرات أسماء النطاق إلى Cloudflare (مجاني)، ثم من Zero Trust > Networks > Tunnels أنشئ نفقًا من نوع cloudflared، وأضف Public Hostname للنطاق يشير إلى `http://localhost:3000`، وانسخ الرمز (token) إلى الملف `data\tunnel-token.txt`، ثم أعد تشغيل المهمة. بعدها يعمل الموقع على نطاقك بشهادة HTTPS ما دام الجهاز شغّالًا ومتصلًا بالإنترنت.

### نشر برابط عام (Render)

1. ادمج الفرع في `main`، ثم من Render: **New > Blueprint** واختر المستودع (يقرأ `render.yaml`).
2. أدخل `ANTHROPIC_API_KEY` إن أردت المساعد الذكي (اختياري).
3. بعد النشر افتح الرابط الذي يعطيك إياه Render؛ أول زيارة تنشئ حساب المالك، فأنشئه فورًا.

**خطة مجانية:** استخدم `render.free.yaml` (حقل Blueprint Path). بلا قرص دائم فتضيع البيانات عند كل إعادة نشر أو تشغيل وتنام الخدمة بعد 15 دقيقة، وتصلح للتجربة فقط.

القرص الدائم (`/data`) يحفظ قاعدة البيانات والنسخ الاحتياطية، ويتطلب خطة مدفوعة. يصلح أي مزوّد آخر يدعم Docker مع قرص دائم.

| متغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | 3000 | المنفذ |
| `DB_FILE` | `data/erp.sqlite` | ملف قاعدة البيانات |
| `COOKIE_SECURE` | 0 | اجعله 1 خلف HTTPS |
| `TRUST_PROXY` | 0 | اجعله 1 خلف وكيل عكسي |
| `ANTHROPIC_API_KEY` | — | يفعّل المساعد الذكي في قسم المراجعة (المفتاح يبقى على الخادم) |
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | نموذج المساعد |
| `BACKUP` | 1 | نسخ احتياطي تلقائي عند التشغيل ثم كل 24 ساعة (0 للإيقاف) |
| `BACKUP_DIR` / `BACKUP_KEEP` | `data/backups` / 14 | مجلد النسخ وعدد النسخ المحفوظة |

فحص الصحة: `GET /healthz`.

## المحاسبة العامة (نواة نظام ERP)

صفحة `/erp.html` (الرابط المباشر): دليل حسابات، قيود يومية مزدوجة، دفتر يومية، ميزان مراجعة، ودفتر أستاذ.
- التحقق من توازن القيد على الخادم (`server/erp.js`)، والمبالغ أعداد صحيحة بأصغر وحدة (بلا فاصلة عائمة).
- لا حذف للقيود: التصحيح بقيد عكسي مرتبط بالأصل. الحسابات التجميعية لا تقبل الترحيل.
- الصلاحيات: القراءة لكل مستخدم، والترحيل لغير «المطّلع»، وإدارة الدليل للمالك والشريك والمدير.
- الواجهة البرمجية: `/api/erp/{accounts,entries,trial-balance,ledger/:code}`.

### المبيعات والمشتريات

في الصفحة نفسها: عملاء وموردون، فواتير مبيعات ومشتريات بضريبة قيمة مضافة لكل بند، سندات قبض وصرف، كشف حساب، ولوحة ملخص (مستحقات، متأخرات).
- كل فاتورة وسند يُرحَّل تلقائياً إلى قيد في المعاملة نفسها (`server/trade.js`): المبيعات من ح/1300 العملاء إلى الإيراد وح/2200 الضريبة، والمشتريات من المصروف وح/2200 إلى ح/2100 الموردين، والقبض والصرف عبر ح/1100 الصندوق أو ح/1200 البنك. يلزم إنشاء دليل الحسابات الافتراضي أولاً.
- ضريبة المدخلات والمخرجات في حساب واحد (2200) فيظهر صافي المستحق للضريبة.
- الفواتير لا تُحذف: الإلغاء (للمالك والشريك والمدير) بقيد عكسي، وغير مسموح لفاتورة عليها مدفوعات. لا يُقبل مبلغ أكبر من المتبقي.
- الواجهة البرمجية: `/api/erp/{parties,invoices,payments,trade/summary}`.

## المعمارية

- `public/`: واجهة الموقع الأصلية (الغلاف `index.html` + 7 أقسام) دون تغيير تصميمها.
- `public/claude-shim.js`: يوفّر `window.claude.use('db' | 'user' | 'downloads')` الذي تعتمد عليه الأقسام، ويتصل بالخادم (قاعدة مستندات بأسلوب Firestore، تحديث فوري عبر SSE).
- `server/`: خادم Express، مخزن مستندات فوق SQLite، حسابات المنصة (scrypt) وجلسات HttpOnly وتقييد محاولات الدخول.
- `public/vendor/`: المكتبات والخطوط محلية (لا اعتماد على الإنترنت). لإعادة توليدها: `npm install && npm run vendor`.

## الاختبار والنسخ الاحتياطي

```bash
npm test            # اختبارات الخادم
npm run backup      # نسخة متسقة إلى data/backups
```

## حدود معروفة

- المساعد الذكي لا يظهر إلا مع وجود `ANTHROPIC_API_KEY`، وحدّه 20 طلباً في الدقيقة لكل مستخدم.
- حسابات الأقسام التي تُضاف يدوياً من صفحة «المستخدمون» لا تستطيع الدخول؛ أضف المستخدمين من `/admin.html`.
- أي مستخدم مسجّل في المنصة يستطيع تقنياً قراءة بيانات المكتب كلها عبر الواجهة البرمجية؛ فصل الصلاحيات الحالي يتم داخل واجهة كل قسم. أضف حسابات للموثوقين فقط.
