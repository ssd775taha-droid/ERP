# البرامج الثلاثة

| الملف | يُثبَّت على | ما يفعله |
|---|---|---|
| `ERP-Server-Setup.exe` | جهاز السيرفر (يلزم Docker Desktop) | قاعدة Oracle + واجهة الويب على المنفذ 3001، مفتوحة لأجهزة الشبكة، مع النسخ الاحتياطي. |
| `ERP-Client-Setup.exe` | أجهزة الموظفين | نافذة تطبيق تفتح النظام كاملاً من السيرفر (حسب صلاحيات المستخدم). |
| `ERP-POS-Setup.exe` | أجهزة الكاشير | نافذة تطبيق تفتح شاشة البيع فقط (وضع `?mode=pos`)، مع خيار الطباعة الصامتة للإيصال. |

العميل ونقطة البيع لا قاعدة بيانات فيهما: يسألان عن عنوان السيرفر عند التثبيت (مثال `192.168.1.10`)، ويُغيَّر لاحقاً من قائمة ابدأ.
عنوان السيرفر يظهر في: ابدأ ← ERP ← ERP Server address. الاتصال HTTP داخل الشبكة المحلية فقط؛ لا تفتح المنفذ على الإنترنت.
